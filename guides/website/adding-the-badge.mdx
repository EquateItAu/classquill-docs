## What the badge is

A small "Powered by ClassQuill" graphic that links back to classquill.com. It's optional — adding
it to your footer helps other tutoring businesses discover ClassQuill through you, and it's the one
thing that resolves the "Share your badge" step on your organisation's getting-started checklist.

## Get your embed code

Go to **Settings → Organisation → ClassQuill badge**. Click either the light or dark badge preview
to copy its embed code — it's plain HTML (a linked image), so it works anywhere a site lets you
paste custom HTML.

## Steps by platform

### WordPress (block theme)

1. Go to **Appearance → Editor** and open the **Footer** template part.
2. Add a **Custom HTML** block and paste the embed code.
3. Save — the footer now shows on every page of your site.

### WordPress (classic theme)

1. Go to **Appearance → Widgets** and pick a **Footer** widget area.
2. Add a **Custom HTML** widget and paste the embed code.
3. Save — footer widgets appear site-wide.

### Squarespace

1. Go to **Settings → Advanced → Code Injection**.
2. Paste the embed code into the **Footer** field and save — it renders on every page.

### Wix

1. Open the footer section of your site in the editor.
2. Choose **Add → Embed Code → Embed HTML**, paste the code, and place it in the footer so it
   shows on every page.

### Elementor

1. Edit your footer template (**Templates → Theme Builder → Footer**).
2. Drag in an **HTML** widget, paste the embed code, then publish.

### Any other website builder

The embed code is a plain `<a>` linking an `<img>` — no script tag, no dependencies. Look for a
**Custom HTML**, **Embed**, or **Code Injection** block in your builder, add it to your footer
template so it's site-wide rather than one page, and paste the code in.

## Keep the link as-is

Leave the link untouched — don't add `rel="nofollow"` or strip the tracking parameter. Both are
needed for the badge to count as a referral back to your organisation.
