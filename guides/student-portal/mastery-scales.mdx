---
title: "Mastery scales and progress levels"
description: "Set your organisation's mastery scale, set a student's level on a topic, and choose what parents see."
---

A mastery scale names the levels a student moves through on each topic, such as Needs work, Developing and Secure. Practice places a student on the scale automatically, and a tutor can set a level by hand. Students, tutors and (unless switched off) parents see the same levels in the Mastery table.

---

## Set up a mastery scale (owners and admins)

1. Go to **Settings**, then **Subjects**, then **Mastery scale**.
2. Pick a starting template: 3, 4 or 5 bands. The default is three bands: **Needs work**, **Developing** and **Secure**.
3. Edit the bands table: rename a band, or change the score where it begins. A band runs until the next one starts, so bands never overlap or leave gaps.
4. To score one subject differently, add a subject override. Every other subject keeps using the organisation's scale.
5. Click **Save**.

Levels tutors have already set keep their band. Nothing in a student's history is rewritten.

---

## Set a level for a student (tutors)

1. Open the student's **Mastery** table. Topics are grouped into sections using your organisation's level names.
2. Pick a topic and choose a level. The row shows **Set by** with your name. A level you set wins over the practice score.
3. If the student practises again and the result lands in a different band, the row shows **Check** so you can confirm your level or change it.
4. Optionally set a target level for a term.

Your note on a level is visible to staff only. A **Secure** level you set unlocks that topic as a prerequisite in the student's learning path.

---

## What parents see

Parents see the Mastery table and weak-area review unless the organisation or a class turns them off.

- Org admins choose this for org classrooms. Tutors choose it for their own groups and 1:1s.
- If any of a child's classes turns Mastery off, the parent sees none of it on the main progress page.
- Parents never see the knowledge map or diagnostic answers.
